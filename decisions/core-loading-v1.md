# Core loading v1

Core #2 consumes a host-approved exact Protocol GenerationCatalog and Registry registrations. Structural/domain, semantic, permission and capability checks precede all factory execution; exact catalog/engine entries must match. Authored mode and generated mode are explicit host choices, with AI-generation support required only in generated mode.

Captured host policies/driver availability cannot be escalated by content. Staged safe diagnostics expose no native exception/source data. Async factory cancellation/deadline and reverse cleanup cover obtained resources; late noncooperative handles are disposed. Factories own hidden partial resources until returning a handle.

Existing wire schemas unchanged; no authored migration. The optional Node loading entry declares Registry/Ajv peers without changing the pure root runtime. Actual production domain/renderer/WASM releases and registry catalog export retain separate gates. Contract: interactive-project/core/docs/loading-v1.md.
